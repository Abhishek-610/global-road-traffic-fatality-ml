# Data-Driven Classification of Global Road Traffic Fatalities Using Machine Learning Models

A Python-based machine learning project for analyzing, classifying, clustering, and predicting global road traffic fatalities using historical road safety data from 2000–2019.

## Project Overview

This project applies multiple **Machine Learning** techniques to investigate global road traffic fatality patterns across different countries. The analysis combines classification, clustering, trend analysis, and future risk prediction to identify factors and patterns associated with road traffic fatalities.

The project implements **Random Forest, K-Nearest Neighbors (KNN), and K-Means Clustering** models and evaluates their performance for road traffic fatality classification and prediction.

## Objectives

* Analyze global road traffic fatality data from 2000–2019.
* Develop machine learning models for classifying road traffic fatality risk.
* Apply K-Nearest Neighbors (KNN) for supervised classification.
* Implement Random Forest for classification and future fatality prediction.
* Use K-Means Clustering to identify groups of countries with similar traffic fatality characteristics.
* Analyze historical trends in road traffic fatalities across different countries.
* Predict future road traffic fatality risk using machine learning models.
* Compare model performance using appropriate evaluation metrics.
